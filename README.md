## Lion LEO Weapon Animations

Add a new set of animations designed specifically for police jobs. Give LEO RP more natural weapon animations for patrols, tactical situations, and everyday police roleplay.

The animations are based on [Ko's Tactical Weapon Reanimations](https://www.lcpdfr.com/downloads/gta5mods/character/54273-kos-tactical-weapon-reanimations/). I selected the animations that fit best with police roleplay.
